Ejercicio: Diagrama de Entidad-Relación

Hacer el Diagrama Entidad-Relación para la Base de Datos de una Tienda Virtual.

La tienda deberá tener las siguientes tablas:

  • Clientes.
  • Categorías.
  • Productos.
  • Facturas.
  • Detalles de la Factura.
  • Proveedores.
  • Pedidos.
  • Detalles de Pedido.

El diagrama debe mostrar las relaciones entre las tablas, así como los atributos de cada tabla y sus tipos de datos. Además, se deben indicar las claves primarias y foráneas de cada tabla.

El diagrama debe ser claro y fácil de entender, y debe cumplir con las normas de diseño de bases de datos relacionales.

Se puede utilizar una herramienta de diagramación como draw.io o Lucidchart para crear el diagrama, o incluso utilizar Microsoft PowerPoint.

Una vez que se haya creado el diagrama, se discutirá en clases la descripción de cada tabla y sus relaciones.
